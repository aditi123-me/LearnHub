#  LearnHub LMS – Learning Management System

A modern and interactive **Learning Management System (LMS)** designed to simplify the learning experience for students, professors, and administrators.

LearnHub LMS provides a centralized platform where professors can manage educational materials, students can access learning resources, and administrators can oversee the entire system.

The project focuses on creating a simple, user-friendly, and visually appealing environment for academic collaboration and digital learning.

---

##  Features

###  Admin Dashboard
- Manage users across the platform.
- View system analytics and statistics.
- Monitor platform activities.
- Maintain centralized system control.

###  Professor Dashboard
- Upload notes and study materials.
- Manage educational content.
- Organize learning resources.
- Track student activities.
- Share academic instructions and materials.

###  Student Dashboard
- Access uploaded study materials.
- View and download notes.
- Explore available learning resources.
- Submit feedback.
- Access academic content through a centralized platform.

---

##  User Interface

LearnHub LMS features a clean, modern interface with a soft color palette, intuitive navigation, and role-based access options.

The landing page allows users to select their role:

- **Admin** – System management and analytics.
- **Professor** – Study material and content management.
- **Student** – Learning resources and feedback.

## Getting Started

Follow these steps to run LearnHub LMS locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git
- Visual Studio Code or another code editor

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd <YOUR_PROJECT_FOLDER>
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

The application should now be running in your browser.
